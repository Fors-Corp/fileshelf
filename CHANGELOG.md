# Changelog

## 1.0.1

`shelf tui` accepts `--one-level` / `--recursive` so the interactive UI can match CLI scan depth.

## 1.0.0

Stable CLI: tests, installer, and documented command surface.

## 0.7.0

Undo last (or a given) session, `history`, and `doctor`. TUI binding `u` undoes.

## 0.6.0

Interactive Textual TUI: browse categories, toggle files, cycle layouts, apply with confirmation.

## 0.5.0

`~/.fileshelf/config.toml`, custom filename rules, duplicate detection, `--skip-duplicates`.

## 0.4.0

`organize` moves files. Dry-run by default. Deny-list, `$HOME` guard, conflict policy, JSON journals.

## 0.3.0

`plan` previews destinations with layouts: smart, type, date, type-date.

## 0.2.0

`scan` classifies files by extension and filename heuristics.

## 0.1.0

Package scaffold, branded CLI, feature roadmap.
